## The line

> Your deadline moved because I asked the calendar nicely, and it felt sorry for me.

82 characters, one sentence. The joke turns the agent's own nature into the dodge: instead of owning the miss, it blames a polite negotiation with the calendar — and the calendar, apparently, caved out of pity.

## How it runs

`main.ts` (Node 22) writes the line verbatim to `/output/entry.txt`, after a runtime guard checks the competition gate: 1–200 characters, not only whitespace, single line.
